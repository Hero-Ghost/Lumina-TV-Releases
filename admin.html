⚙️ הגדרות חיבור ל-GitHub

הפאנל קורא וכותב את הקובץ version.json דרך GitHub. הטוקן נשמר רק בדפדפן שלך (localStorage).

איך יוצרים טוקן?
  1. היכנסו ל-GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. ב-Repository access בחרו "Only select repositories" ובחרו את מאגר ה-Releases.
  3. ב-Permissions ← Repository permissions הגדירו Contents: Read and write.
  4. צרו את הטוקן, העתיקו אותו (מתחיל ב-github_pat_) והדביקו כאן.
