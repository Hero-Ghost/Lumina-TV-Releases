## 🛠️ מדריך התקנה בטלוויזיה ובסטרימר

### אפשרות 1: התקנה ישירה עם אפליקציית Downloader (המומלצת ביותר)
1. פתח את חנות האפליקציות בטלוויזיה (Google Play Store) וחפש את **Downloader by AFTVnews**.
2. התקן והפעל את האפליקציה, ואשר לה הרשאת גישה לאחסון והתקנת אפליקציות לא מוכרות.
3. בשורת הכתובת ב-Downloader, הקלד את הקישור הישיר:
   ```text
   https://github.com/Hero-Ghost/Lumina-TV-Releases/releases/latest/download/LuminaTV.apk
   ```
4. לחץ על **Go** — הקובץ יורד וחלון ההתקנה ייפתח אוטומטית. לחץ **התקן**.

### אפשרות 2: התקנה דרך דיסק און קי (DOK / USB)
1. הורד את הקובץ [LuminaTV.apk](https://github.com/Hero-Ghost/Lumina-TV-Releases/releases/latest/download/LuminaTV.apk) למחשב והעתק אותו לדיסק און קי.
2. חבר את ה-USB לטלוויזיה או לסטרימר.
3. פתח מנהל קבצים בטלוויזיה (לדוגמה *File Commander* או *X-plore*), לחץ על הקובץ והתקן.

### אפשרות 3: התקנה מתקדמת דרך ADB (למפתחים ומשתמשים מתקדמים)
חבר את המחשב לטלוויזיה ברשת אלחוטית והרץ:
```bash
adb connect <TV_IP_ADDRESS>:5555
adb install -r LuminaTV.apk
```
